# M3 tracking diagnosis / 跟踪失败诊断

Date: 2026-09-13. Status: diagnostic evidence collected; no production fix applied.

## 结论

当前不能把两类失败统一归因于 PID gain 太小，也不能统一归因于拐角太急。

1. **斜线终点超时主要暴露欠驱动终点策略的非目标静止平衡，以及姿态环的静态偏差。**
   执行器未饱和，车辆停在目标附近；前向投影误差为零并不意味着二维位置误差为零。
2. **detour 第一次碰撞发生在第一个参考拐角之前。**
   初始姿态瞬态、斜线跟踪偏差和跟踪误差裕量都需要检查。仅给拐角减速不能解释或保证
   消除这次碰撞；对齐初始姿态也未能避免碰撞。
3. **独立转角扫描支持“减速能减小本组实验的运动阶段误差”，不支持“减速即可可靠完成任务”。**
   大角度出现短时力矩饱和，同时还存在静态姿态误差、时间进度误差和终点问题。

这里的结论针对 synthetic v1 + 当前 PID + 当前定时折线参考，不是实际 UUV 的能力边界。

## 1. 斜线：终点位置没有收敛，但车辆已进入近似静止平衡

Ascending 在 120 s 的观测值：

| 量 | 值 |
| --- | ---: |
| 最终位置 | (9.040930, -3.258867) m |
| 目标 | (9, -3) m |
| 位置误差 | 约 0.262 m，超过 0.25 m 门槛 |
| 深度误差，reference − actual | +0.258867 m |
| 前向投影位置误差 | −0.00000480 m |
| 内部 surge target | −0.00000168 m/s |
| 实际 u | −0.000000499 m/s |
| 实际 w / q | 约 −5.95e−12 m/s / −1.09e−8 rad/s |
| 实际 pitch | 0.156795 rad |
| 参考切向 pitch | 0.244979 rad |
| PID 有效 pitch target | 0.193205 rad |
| pitch P / I / D | 0.436921 / 0.500000 / 约 0 N·m |
| 输出力矩 | 0.936921 N·m，上限 8 N·m |

Descending 给出上下镜像结果。运动阶段最大力矩约 2.946 N·m，未饱和。

控制器的终点 surge 命令依赖：

```text
forward_error = cos(actual_pitch)*dx + sin(actual_pitch)*dz
u_target = reference_u + position_gain*forward_error
```

终点 `reference_u=0`。因此，二维误差仍非零但恰好接近当前身体前向的法向时，
`u_target≈0`。又没有直接 heave 执行器，车辆可以在非目标位置停止。
继续延长仿真不是可靠解决方案：这里观测到的是近似平衡，不只是仍在缓慢接近目标。

此外，depth correction 使用 `sign(u_target)`。本例末段存在极小的负 surge target，
因此修正方向为反向，最终 pitch 目标低于参考 pitch。零速附近该符号切换也是后续
终点策略需要处理的边界，而不是 angle wrapping 错误。

### 静态姿态偏差有明确的力矩依据

Physics 的恢复项为 `6*sin(pitch)`。在原斜线参考姿态，静态平衡需要
`6*sin(atan2(2,8))≈1.455214 N·m`。但 PID 在姿态误差和 q 都为零时，
积分项最多只有 `pitch_ki*pitch_integral_limit=0.5*1=0.5 N·m`，且没有
恢复力矩前馈。因此零姿态误差静态平衡无法由当前积分容量维持。

在实际终点姿态，恢复力矩约为 0.936921146 N·m，实际控制为 0.936921126 N·m，
两者几乎平衡。非零姿态误差提供了所需的 P 项。
这说明 **积分限幅不等于执行器饱和**；增大 Kp 可能改变误差大小，却不自动修复
终点欠驱动位置收敛机制。只补恢复力矩前馈也不能单独保证二维终点位置收敛。

## 2. Detour：在参考转弯前已违反安全间隙

| 对照 | 结果 | 终止时间 | 运动阶段最大几何偏离 | 最大 pitch 力矩 |
| --- | --- | ---: | ---: | ---: |
| 原 detour | COLLISION | 8.20 s | 0.639 m | 6.717 N·m |
| 仅对齐初始 pitch | COLLISION | 8.40 s | 0.447 m | 3.432 N·m |
| 仅移除障碍，保留边界 | OUT_OF_BOUNDS | 18.75 s | 1.493 m | 8.000 N·m |
| 移除障碍并对齐初始 pitch | OUT_OF_BOUNDS | 18.70 s | 1.526 m | 8.000 N·m |

移除障碍的对照刻意保留原边界和原路径，不称为无限开放空间；真正的大开放空间
由后面的 Corner Tracking Test 提供。

原参考到达第一拐角的时间为 **9.433981 s**，晚于 **8.20 s** 的首次碰撞。
碰撞是 vehicle radius 0.2 m + safety margin 0.1 m 的完整运动段检查结果，
不要求车辆中心先进入墙内。终止点横向偏差约 0.641 m，沿参考方向落后约 0.229 m。

碰撞前力矩没有达到上限，也没有超过 90% 上限。最后一步 PID 有效姿态误差约
−10.56°，I 项已达 −0.5 N·m；不是车辆一直用满 8 N·m 仍无法转向。
对齐初始 pitch 减少了偏离，但仍碰撞，排除了“只有起始姿态不一致”这个单一解释。
移除障碍后才能观察后续转角处短时饱和；该后续现象不能倒过来解释前面的首次碰撞。

因此，B 类控制响应/静态力矩问题和未预留足够执行误差裕量有直接证据；C 类定时参考
落后也存在，但不能用纯时间延迟解释全部横向偏差。尚未进行 progress-aware reference
对照，不能声称已证明改成进度参考就能避免碰撞。

## 3. Isolated Corner Tracking Test

初始水平段 5 m，第二段 5 m；正转角 15/30/45/60/90/120°；速度
0.2/0.3/0.4/0.5 m/s；无障碍、无流、边界 x∈[−30,30]、z∈[−50,0]。
初始姿态水平且 u 等于参考速度，以减小从静止加速的干扰；PID 积分从零开始。

### 包络的含义与局限

每案保存定时拐角前一个样本至参考结束的实际中心轨迹包围盒，以及数值运动弦段到
几何路径的距离保守上界。利用距离函数的 1-Lipschitz 性质，每条弦段的上界采用
端点距离较大值加弦长一半。若用于参考路径的圆管安全裕量，还需另加 vehicle radius
和 safety margin；不能把中心距离直接当作可通行净宽。

这些只是已测条件下的包络，不是所有初态、流场和载具参数的保证；也不覆盖 RK4 内部
真实曲线。扫描仅包含正角、固定长度和固定初态，无噪声、多随机种子或 dt 收敛审计。

### 大姿态的额外控制律适用范围

在 w≈0、u>0 时，`d(z_dot)/d(pitch)=u*cos(pitch)`。
当前 depth-to-pitch correction 只按 surge target 的正负改变符号，不按 cos(pitch)
改变符号。因此超过 90° 时，它不能被视为通用的正确深度负反馈；接近 90° 也失去
一阶灵敏度。120° 的不佳结果不应仅解释为“需要更低速”。这是由现有控制律和
运动学直接推导的适用范围警告，不是本次已经隔离验证的唯一失败原因。

## 4. 建议的下一步，不在本次擅自实施

1. **先设计终点接近/停稳策略**：明确欠驱动车辆如何在低速时消除二维剩余误差，
   避免仅靠前向投影误差的零点停在目标区域外。保持现有容差不变。
2. **做姿态保持独立对照**：比较恢复力矩前馈、积分容量和现有 PI，分别记录稳态误差、
   输出余量和抗饱和行为；不要同时改变多个参数。先解决直线斜航偏差，再评价转角收益。
3. **再设计 Trajectory v0.7.1 的减速对照**：在相同几何路径下比较固定速度和角点减速，
   区分航迹改进与仅仅延长时间。若加入 progress-aware reference，单独作为另一个因素。
4. **不要直接默认 stop–turn–go 可行**：在有恢复力矩、欠驱动、终点控制仍有缺陷的模型里，
   零速定点转向和再次启动需要独立验证。

本次没有修改 PID gains、恢复力矩补偿、时间参考策略或生产版轨迹速度调度。
