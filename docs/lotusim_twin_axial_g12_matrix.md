## 验收修补

新入口中的重复性同时要求：

1. P0 与 P0_repeat 各自完整验收通过，并且原始记录重放验证通过。
2. 时间序列从 0.05 s 开始、步长连续，无重复时间；按相同仿真时间比较位置。
3. 最大位置差 ≤0.02 m，到达时间差 ≤0.10 s，终止时间差 ≤0.10 s，并检查公共时间覆盖。

组汇总明确检查重复运行自身通过；不能以重复性位置差为零掩盖重复试验的跟踪、到达或包络失败。完整 Python 前置门禁要求54条全部通过、9组重复性通过、全部原始记录可重放、冻结源码与当前源码一致。原N6至少4/5、P0必须通过及所有名义条目安全的要求没有放宽；54条全通过是本阶段附加门禁。
