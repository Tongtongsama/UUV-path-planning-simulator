## 1. 通俗版

### 1.1 3-DOF 纵平面扔掉了什么

一台 UUV 有 6 个自由度。自研物理只保留 3 个：

| 保留 | 符号 | 含义 |
|---|---|---|
| 前进/后退 | `x` | 东向位置（ENU） |
| 上升/下潜 | `z` | 天向位置（ENU） |
| 抬头/低头 | `θ` | 俯仰角 |

对应速度：`u`（纵向）、`w`（垂向，**向下为正**）、`q`（俯仰角速度）。

被扔掉的是：横向位置 `y`、横滚 `φ`、艏向 `ψ`。**这不是"设为 0"，而是结构上不存在**——Core 里它们的值必须严格为 0（容差 `1e-12`），否则 Physics 直接拒绝。这是"子空间"而非"近似"。

为什么敢扔：研究对象是"在竖直剖面里绕过挡板"，主要机动是上浮下潜 + 抬头低头；横向漂移由水流引起、由控制器当作扰动处理，而非主动控制。

### 1.2 一条方程，六个"力从哪来"

```
M·ν̇ = B·τ  −  C_RB(ν)·ν  −  C_A(ν_r)·ν_r  −  D(ν_r)·ν_r  −  g(θ)  +  M_A·ν̇_c
       ↑         ↑              ↑                ↑           ↑         ↑
     推力    刚体科氏      附加质量科氏        阻尼       恢复力矩   水流附加项
```

**(1) `M = M_RB + M_A`：质量 + 附加质量**

`M_RB = diag(m, m, I_y)` 是真实质量与转动惯量。
`M_A = diag(A_u, A_w, A_q)` 是**附加质量**——推一个物体在水里走，周围的水也被带着走，"感觉上"变重了。

`A_u = 5` 的意思是：纵向看，它像重了 5 kg。
总质量矩阵 `diag(20+5, 20+8, 8+2) = diag(25, 28, 10)`。

> 容易踩的坑：文献中的水动力导数 `X_u̇` 通常是**负**的，而这里存的是**正**的"附加惯性"。文档明确 `A_u = −X_u̇`，转换在入库前完成。直接抄文献数字会让符号反掉。

**(2) `C_RB(ν)·ν`：刚体科氏项**

```
C_RB·ν = [ m·q·w ,  −m·q·u ,  0 ]
```

直觉：飞行器一边绕 Y 轴转（`q`）一边沿 Z 走（`w`），会在 X 方向"被甩"出一个力，大小 `m·q·w`。这是旋转角速度叉乘线速度的结果。

第三行为什么是 0？纵平面里没有能产生俯仰力矩的科氏耦合——俯仰是绕自身轴转，不"甩"自己。

**(3) `C_A(ν_r)·ν_r`：附加质量科氏项**

```
C_A·ν_r = [ A_w·w_r·q ,  −A_u·u_r·q ,  (A_u − A_w)·u_r·w_r ]
```

结构与刚体项同源，但用**相对速度** `ν_r`（相对水），且多了第三行：纵向与垂向速度不等时，会产生俯仰力矩。这是附加质量各向异性（`A_u ≠ A_w`）的直接后果——水在"前后"和"上下"被排开的难易不同，斜着走就会有力矩。

**(4) `D(ν_r)·ν_r`：阻尼**

```
D(ν_r)·ν_r = D_L·ν_r + D_Q·(|ν_r| ⊙ ν_r)
```

线性项 + 二次项。低速时线性主导（粘性），高速时二次主导（压差阻力）。参数表因此有两组：`diag(4,6,3)` 与 `diag(1,1.5,0.5)`。

用 `|ν_r|⊙ν_r` 而非 `ν_r²`，是为了**保号**：反向运动时阻尼也要反向，否则会变成"负阻尼"把系统吹飞。

**(5) `g(θ) = [0, 0, k·sinθ]`：恢复力矩**

`k = 6`，带负号进方程：抬头了往回压，低头了往回抬——**静稳定**。

为什么是 `sinθ` 而不是 `θ`？真实恢复力矩来自重力与浮力的力臂差，力臂正比于 `sinθ`。小角度下 `sinθ ≈ θ`，所以小扰动时它像一根弹簧。

> 必须说清楚：这里没有真正的重心/浮心几何，`k = 6` 是一个**集总系数**。它能复现"回中"，但**不能**用来讨论稳心高度、横滚稳定性。

**(6) `M_A·ν̇_c`：水流附加项（最容易漏的一项）**

设世界系有恒定水流 `[v_cx, v_cz]`。船在转（`q`），那么在船体系里看，**这股水流的方向也在转**：

```
ν̇_c = [ −q·w_c ,  q·u_c ,  0 ]
```

正确做法：

1. 世界流换算到船体系：`ν_c = A(θ)·[v_cx, v_cz]`
2. 相对速度：`ν_r = ν − ν_c`
3. 附加质量项本是对**相对速度**求导，`d(ν − ν_c)/dt` 会多出 `−M_A·ν̇_c`
4. 挪到右边变成 `+M_A·ν̇_c`

**若省掉这一项**，就默认了"水流在船体系里不动"，即船不转或流速为零。文档明确：省略该项仅对零流或零俯仰角速度成立。

顺带一个漂亮的数学性质：变换矩阵

```
A(θ) = ⎡ cosθ   sinθ ⎤
       ⎣ sinθ  −cosθ ⎦
```

满足 `A = Aᵀ = A⁻¹`（对合矩阵）。所以"世界→船体"和"船体→世界"用的是**同一个矩阵**，代码里 `world_current_to_body` 直接复用 `body_to_world_velocity_matrix` 的 `[:2,:2]` 块——不是偷懒，是数学上确实对称。

### 1.3 数值积分：为什么是 RK4

每步先把 `ν̇` 解出来：

```python
nu_dot = np.linalg.solve(self.parameters.mass, rhs)
```

**为什么 `solve` 而不是求逆再乘？** 数值上更稳，且 `M` 是对角正定矩阵，几乎零成本。

| 积分器 | 每步计算量 | 理论阶数 | 实测阶数（本项目） |
|---|---|---|---|
| Euler | 1 次导数 | 1 | 1.006 ~ 1.115 |
| **RK4（默认）** | 4 次导数 | 4 | **3.882 ~ 4.070** |

实测数据来自 [validation/reference_cases/physics_v0.4_results.json](../../validation/reference_cases/physics_v0.4_results.json)：步长 0.2 → 0.025 逐次减半，与 SciPy DOP853（`rtol=1e-11, atol=1e-13`）对比，再算观测阶数。

| 算例 | RK4 终值 L2 误差（h=0.2 → 0.025） | Euler 终值 L2 误差 |
|---|---|---|
| 阻尼自由响应 | 5.2e-7 → 1.3e-10 | 4.2e-2 → 5.0e-3 |
| 恒定纵向推力 | 5.3e-8 → 1.3e-11 | 7.8e-2 → 9.6e-3 |
| **含流 + 俯仰** | 3.8e-6 → 9.5e-10 | 7.5e-2 → 8.2e-3 |

第三个算例误差高约一个数量级，因为它是唯一 `q ≠ 0` 且 `ν_c ≠ 0` 的算例——`M_A·ν̇_c` 只有在 `q ≠ 0` 时才非零。**这个算例存在的意义就是专门验证该项写对了。**

**为什么工程上用 RK4 而非更高阶？** 4 次导数/步 × 2400 步，代价可接受；更高阶（如 DOP853）在固定步长下收益递减，且会破坏"每步计算量恒定"的可预测性。

### 1.4 参数：一套数，两个后端

这是仓库里最值得注意的一致性证据。3-DOF 的 YAML（[config/vehicles/uuv_3dof_synthetic_v1.yaml](../../config/vehicles/uuv_3dof_synthetic_v1.yaml)）与 xdyn 的 6-DOF 模型（[ros2/twin_axial_v2/model.py](../../ros2/twin_axial_v2/model.py)）用**同一套水动力参数**：

| 量 | 3-DOF | xdyn 6-DOF | 一致 |
|---|---|---|---|
| 质量 | `20` | `20` | ✅ |
| 俯仰惯量 | `8` | `8` | ✅ |
| 附加质量（纵/垂/俯） | `5 / 8 / 2` | `5 / 8 / 2` | ✅ |
| 线性阻尼（纵/垂/俯） | `4 / 6 / 3` | `4 / 6 / 3` | ✅ |
| 二次阻尼（纵/垂/俯） | `1 / 1.5 / 0.5` | `1 / 1.5 / 0.5` | ✅ |
| 恢复系数 | `6` | `6`（`−6 sinφ`、`−6 sinθ`） | ✅ |
| 推进器 | 抽象 `τx, τm` | 上下双推进器 `±0.25 m`、各 `±15 N` | 几何新增 |

即：**3-DOF 只用了 6-DOF 参数集的 `x-z-θ` 三个通道**。这解释了为什么 A 栈的 Python 结果对 B 栈有预测力——不是巧合，是同一组系数。

xdyn 多出的部分是 6-DOF 独有：

```
附加质量: diag(5,5,8,2,2,2)   ← 多出 sway 5、roll 2、yaw 2
阻尼:     diag(4,6,6,3,3,3)   ← 多出 sway 6、roll 3、yaw 3
推进器:   M = 0.25·(T_lower − T_upper)
```

### 1.5 3-DOF 与 6-DOF：子空间投影，不是简化版

| 维度 | 3-DOF | xdyn 6-DOF |
|---|---|---|
| 状态 | `(x,z,θ,u,w,q)` | 全部 12 维 |
| 横向运动 | 结构上不存在 | 由耦合产生 |
| 横滚 | 不存在 | `−6 sinφ` 回中，无横滚-艏向耦合建模 |
| 状态裁剪 | 严格断言非活跃为 0 | **完全不裁**，xdyn 自己积分 |
| 求解 | 自研 `solve(M, rhs)` | xdyn 内部 RK4，每级求值 |
| 电流 | `ν_c` + `M_A·ν̇_c` 显式 | 同思路，以"水动力增量"注入（见 06） |

**最后一行很重要**：xdyn 有内置"均匀流"功能，但项目**故意不用**，而是在 `model.yml` 里注入 `maneuvering` 力模型，手写相对速度的阻尼差与科氏差。原因：该版本 xdyn 的内置流既加到运动学、又加到阻尼，会**重复计算**。所以选择"只有一个绝对状态持有者"。

这是典型工程判断：**不是"哪个功能好用就用哪个"，而是"谁能保证只算一次"**。

## 2. 严谨版：学术总结

### 2.1 控制方程

设 `ν = [u,w,q]ᵀ`、`ν_r = ν − ν_c`、`ν_c = [u_c, w_c, 0]ᵀ`：

```
M ν̇ = B_τ τ − C_RB(ν)ν − C_A(ν_r)ν_r − D_L ν_r − D_Q(|ν_r| ⊙ ν_r) − g(θ) + M_A ν̇_c

M     = diag(m + A_u, m + A_w, I_y + A_q)
B_τ   = diag(1, 0, 1)
g(θ)  = [0, 0, k_θ sin θ]ᵀ
ν̇_c   = [−q w_c, q u_c, 0]ᵀ
```

运动学：

```
ẋ = u cosθ + w sinθ
ż = u sinθ − w cosθ
θ̇ = q
```

### 2.2 约化后的科氏矩阵

```
        ⎡ 0    m q   0 ⎤              ⎡ 0        0       A_w w_r ⎤
C_RB =  ⎢−m q   0     0 ⎥    C_A =   ⎢ 0        0      −A_u u_r ⎥
        ⎣ 0     0     0 ⎦              ⎣−A_w w_r  A_u u_r    0    ⎦
```

两者均**斜对称**（`Cᵀ = −C`），故 `xᵀ C(x) x ≡ 0`。物理含义：科氏/向心力不做功，无阻尼系统动能守恒。这是约化正确性的必要条件，也是单元测试检查项（矩阵项、斜对称、二次型功率为零、展开标量方程）。

注意 `C_RB` 作用于**绝对速度**、`C_A` 作用于**相对速度**——这一非对称处理是相对运动建模的标准形式；若两者都作用于绝对速度，会在有流时引入伪力。

### 2.3 坐标变换的对合性

```
A(θ) = ⎡ cosθ   sinθ ⎤,    A = Aᵀ = A⁻¹
       ⎣ sinθ  −cosθ ⎦
```

**A 是对合矩阵**。故世界→船体与船体→世界共用同一线性算子，实现上无需维护两个矩阵。该性质源于"ENU 天向为正"与"SNAME 垂向为正"的符号对立：一次反射（z 轴反向）复合一次旋转，其平方为单位阵。

### 2.4 数值离散与收敛性

```
x_{k+1} = Φ_h(x_k, τ_k, ν_c,k),   Φ_h ∈ {Euler, RK4}
```

`M` 对称正定对角，条件数 `max(25,28,10)/min(25,28,10) = 2.8`，数值条件良好；用 `solve` 而非显式求逆。

**收敛性证据**（h: 0.2 → 0.025，基准 DOP853，`rtol=1e-11`、`atol=1e-13`）：

| 算例 | 观测阶数 RK4 | 观测阶数 Euler | RK4 终值误差（h=0.025） |
|---|---|---|---|
| 阻尼自由响应 | 3.988 / 3.993 / 3.998 | 1.025 / 1.012 / 1.006 | 1.28e-10 |
| 恒定纵向推力 | 4.049 / 4.020 / 3.946 | 1.014 / 1.007 / 1.003 | 1.27e-11 |
| 含流 + 俯仰 | 3.882 / 3.998 / 4.070 | 1.115 / 1.056 / 1.028 | 9.49e-10 |

观测阶数与理论一致；第三个算例（唯一 `q ≠ 0 ∧ ν_c ≠ 0`）误差高约一个数量级，反映 `M_A ν̇_c` 引入的附加耦合，即为该项的专项验证。

### 2.5 参数同构命题

**命题**：自研 3-DOF 模型与 xdyn 6-DOF 模型在 `(x,z,θ)` 子空间上参数同构。

**证据**：`mass_rb = diag(20,20,8)`、`mass_added = diag(5,8,2)`、`damping_linear = diag(4,6,3)`、`damping_quadratic = diag(1,1.5,0.5)`、`k_θ = 6` 与 xdyn 的 `[20,20,20,8,8,8]`、`[5,5,8,2,2,2]`、`[4,6,6,3,3,3]`、`[1,1.5,1.5,.5,.5,.5]`、`−6 sinθ` 对应通道逐项相等。

**推论**：两后端在纵平面内的**开环**响应应当一致；差异只能来自 6-DOF 新增通道（sway/roll/yaw）经耦合回灌到纵平面，以及推进器几何与饱和。这为"A 栈结果可作 B 栈必要非充分筛选"提供了参数层面的依据（第 1 段 §2.5 的结构性论证在此获得数值支撑）。

### 2.6 建模边界（必须声明）

1. **恢复力矩为集总系数**：`k_θ sinθ` 不来自重心/浮心几何，无法讨论稳心高度、横滚稳性；xdyn 侧同样用 `−6 sinθ` 人造回中，而非真实浮力分布。
2. **中性浮力假设**：平移方向无净浮力，故 `g` 仅有俯仰分量；排除定深漂移与压载调整。
3. **对角化假设**：`M_RB`、`M_A`、`D` 均为对角，忽略惯性积、附加质量交叉项与操纵性耦合（如 `M_ẇ`、`Z_q̇`）。
4. **无推进器动力学**：3-DOF 侧 `τ` 为理想广义力，无转速-推力曲线、无电机滞后、无死区；6-DOF 侧为理想可逆推力 `±15 N`，同样无 RPM 转换。
5. **参数为合成值**：`uuv_3dof_synthetic_v1` 明确标注 test-only，**不得**表述为 REMUS 100 或任何实测载具。
