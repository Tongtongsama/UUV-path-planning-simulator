## 1. 通俗版

### 1.1 规划与轨迹是两件事

| | 输入 | 输出 | 关心 |
|---|---|---|---|
| 规划 | 世界 + 起终点 + 净空要求 | 折线 `Path` | 不撞、连通 |
| 轨迹 | 折线 + 速度 | 带时间戳的 `Trajectory` | 什么时候到哪 |

规划完全不知道"船有多快、转得多慢"；轨迹完全不知道"哪里不能走"。这个分工让两者可以独立替换与独立验收，代价是**都不保证动力学可行**——可行性由闭环实验回答，不是由规划器回答。

### 1.2 A* 的四件事

**(a) 栅格化**

把连续空间切成 0.5 m（S4）或 1.0 m（默认）的格子。每个格子只记"能不能过"：

```
occupied = not world.is_pose_valid(节点, required_clearance)
```

注意：**节点级认证**。它只说"这个格子中心点放得下船"，不说"格子之间走得通"。所以 A* 每扩展一条边，还要单独做一次**连续段碰撞检查**：

```python
if neighbor in closed or not space.is_segment_valid(pose, target, radius):
    continue
```

这一步是必须的，否则对角穿过一个墙角也会被判为连通。

**(b) 禁止切角**

8 邻接时，对角移动要求两个正交邻居都空闲：

```python
if di and dj and (not free((i+di,j)) or not free((i,j+dj))):
    continue
```

否则会出现"船从两个障碍的接触点之间斜穿过去"的经典错误。

**(c) 启发式为什么是 `max(0, d − tol)`**

因为目标是**区域**不是点。距离目标 0.4 m，而容差是 0.5 m 时，已经算到达，剩余代价应为 0。若用 `h = d`，会把"已到达"估成"还差 0.4 m"，导致搜索无谓扩展。

这个 `h` 是**可采纳**的（admissible）：它永不高估真实剩余代价，所以 A* 在给定图上是**最优**的。

**(d) 虚拟终点 `None`**

起点和终点通常不在格点上（因为它们在任意坐标）。做法是：

- 起点：取周围最多 4 个格点，逐个检查"连线是否安全"，得到若干合法起点；
- 终点：同样取 4 个邻格，但**额外允许一条"跳到精确终点"的边**，用一个虚拟节点 `None` 表示。

```python
if node in goals:
    edges.append((None, goal))     # 精确终点连接器
```

这样终点精度不受栅格分辨率限制。否则 0.5 m 栅格意味着终点最多偏 0.35 m，而容差只有 0.25 m 时就会**永远无法到达**。

### 1.3 安全捷径：为什么能省 60% 的时间

S4 场景（5 个矩形障碍，0.5 m 栅格，8 邻接）的实测：

| 方案 | 长度 m | 总转角 ° | 最大离散转角 ° | 拐点数 |
|---|---:|---:|---:|---:|
| A 原始 A* | 18.485 | **765.0** | 45.0 | 17 |
| B 安全捷径 | 17.207 | **69.8** | 40.3 | 2 |
| C B + 圆角 | 17.073 | 69.8 | **1.4** | 2 |

注意：B 比 A 只短了 **6.9%**，但总转角从 **765° 降到 70°**。

闭环结果：

| 方案 | 到达 s | 实际净距 m | RMS m | 最大误差 m | 结果 |
|---|---:|---:|---:|---:|---|
| A 原始 A* | **132.90** | 1.630 | 0.195 | 0.533 | passed |
| B 安全捷径 | **52.45** | 1.565 | **0.084** | **0.222** | passed |
| C 圆角 | 59.10 | 1.199 | 0.172 | 0.455 | passed |

**这才是重点**：栅格路径的"锯齿"（17 个 45° 拐点）对闭环的伤害远大于长度。
到达时间从 132.9 s 降到 52.5 s（−60.5%），RMS 从 0.195 降到 0.084（−57.1%）。

原因不难理解：每一个 45° 拐点都要求船"转 45° 再走"，而 UUV 转向慢（前视 2.3 m、限速 0.10 m/s），拐一次要十几秒。17 次拐弯就是几分钟。

**捷径的算法**（`simplify_path` + 生成器里的贪心）：

```
从点 i 出发，尝试最远的 j；若 segment_valid(i, j) 不成立，则 j 递减；
直到找到最远的可见点，跳到它。
```

注意它**不是**"去掉共线点"那么简单——它真的在"能看见就直接飞过去"。
风险是：贪心最远可见会跨过"更优"的中间点（比如绕开一个凸角的更短路线），所以文档明确写"只在有限候选集内最优，不声称全局最优"。

### 1.4 多候选打分：当 A* 不够用时

A* 只优化**长度**。但实际任务里，"贴着障碍走"和"走在通道中间"长度差不多，风险差很多。

`CandidatePlanner` 的做法：跑 5 次 A*，每次把安全裕量加一点（buffer = 0, 0.15, 0.3, 0.5, 0.75 m），得到 5 条不同"胆量"的路径，再用几何代价挑一条：

```
cost = 长度 + 1.0×总转角 + 2.0×净空不足积分 + 2.0×拐点间距不足 + 0.25×拐点数
```

三个"不足"项的定义：

- **净空不足积分**：沿路径采样，`max(0, 0.75 − 净空)` 对弧长积分。即"离障碍少于 0.75 m 的部分，越近、越长，罚得越多"。
- **拐点间距不足**：`max(0, 4.0 − 段长)` 求和。即"两个拐点挨得太近"要罚，因为船来不及摆正。
- **未知转角**：每个拐点固定罚 0.25。

**这是一个加权启发式排序，不是多目标优化。** 权重是人工设定（米/弧度混用），文档明确写"经验权重、非物理可行性证明"。

### 1.5 轨迹生成：四步流水

```
去重 → 贪心捷径 → 等距细分 → 等速时间戳
```

**(a) 去重**：删掉连续重复点（A* 可能产生 `p, p`）。

**(b) 贪心捷径**：同 `simplify_path` 的思路，但用更大的让步（从最远点开始退）。

**(c) 等距细分**：每段按 `ceil(长度 / sample_spacing)` 切成 n 份。

```python
counts.append(max(1, ceil(length / sample_spacing)))
```

关键细节：**保留原拐点**。

```python
samples.append(b if k == count else 插值点)
```

即每段最后一个采样点直接取端点 `b`，而不是插值算出来的位置。这样拐角坐标不会被浮点误差磨掉。

**(d) 等速时间戳**：

```
Δt = 段长 / nominal_speed
```

即 `s(t) = v·t`，**匀速**，不是最小时间、不是梯形速度、不是考虑转弯减速。

**为什么用等速？** 三个理由：

1. **可归因**：等于把"速度规划"这件事交给制导层（G12 的 bend-based 减速），轨迹层不掺和。若轨迹层也做减速，两层叠加就无法归因。
2. **可比**：所有方案用同一速度，差异只能来自几何。
3. **端点零速**：最后一个状态 `twist = zero()`，让"到达"有明确的速度定义。

### 1.6 圆角 fillet：怎么保证圆弧不撞

这是本段技术含量最高的部分。做法：

**(a) 定 trim 长度**

```
t = R · tan(|α|/2)
```

`α` 是转角。`R = 1 m` 固定。trim 是"从拐点往两边各退多远开始转弯"。

**(b) 拒绝三种不可平滑情形**

| 情形 | 判据 | 原因 |
|---|---|---|
| 反向（U 形回转） | `|α| ≥ π − 1e-9` | 圆角会退化 |
| 相邻 trim 重叠 | `t_i + t_{i+1} > L_i` | 两段圆弧会互相吃掉 |
| 点预算不足 | `len(points) + n + 2 > max_points` | 资源上限 |

**(c) 圆弧采样：两个独立上界取小**

```python
step_limit = min( 2·acos(1 − max_sagitta/R),          # 弓高约束
                  2·asin(max_chord/(2R)) )            # 弦长约束
n = ceil(|α| / step_limit)
sagitta = R·(1 − cos(|α|/(2n)))
```

- 弓高（sagitta）是"圆弧中点离弦的垂直距离"；
- `max_sagitta = 0.001 m`，`max_chord = 0.1 m`。

**为什么"用弦的胶囊体"能证明圆弧安全？**

数学事实：一段圆弧完全落在"弦 + 弓高"构成的**弓形区域**内；而弓形区域又被"弦的胶囊体（半径 = sagitta）"包含。

所以，如果

```
is_segment_valid(p_k, p_{k+1}, required_clearance + sagitta)
```

对每一小段弦都成立，则圆弧上的每一点离障碍都 ≥ `required_clearance`。

这是**保守但可证**的：用"弦 + 弓高"换取"不需要对圆弧做连续的圆-矩形距离计算"。

**(d) 一个容易忽略的约束：`lookahead ≤ 0.8 × 弧长`**

```python
if config.lookahead > config.max_lookahead_fraction * sampled_length:
    return reject('LOOKAHEAD_TOO_LONG_FOR_ARC')
```

为什么？如果圆弧总长只有 0.3 m，而 LOS 前视距离是 0.5 m，那么前视点**直接跳过了整段圆弧**，落在圆弧之后的直线上——圆角对制导完全不可见，白做。

所以圆角半径、转角、前视距离三者是耦合的：`R` 太小或转角太小，圆弧就"看不见"。

### 1.7 S4 的 A/B/C/D 四条路，与一个反直觉结论

| 代号 | 内容 | 状态 |
|---|---|---|
| **A** | 原始 A* 折线 | 基线 |
| **B** | A + 安全捷径 + 共线消除 | ✅ 最优 |
| **C** | B + 二次贝塞尔圆角 | 几何更平滑，**闭环更差** |
| **D** | 独立候选：最后 4 m 水平终点段 | 独立验证，5 条真实 pilot |

**C 为什么更差？** 三条实测证据：

- 到达时间 52.45 → **59.10 s**（慢 6.65 s）
- RMS 0.0837 → **0.1716 m**（翻倍）
- 实际净距 1.565 → **1.199 m**（更贴障碍）

解释（文档给的可信机制，尚未做消融隔离）：**G12 的速度是按"前方 2 m 的弯度"规划的**。圆角改变了局部几何，于是改变了 bend，于是改变了参考速度，于是改变了整条轨迹的时序。几何平滑改善了"路径本身"，但把"速度-转向时序"打乱了。

**这是一个非常有价值的负面结果**：它说明"更平滑的几何"不等于"更好的闭环"，因为下游制导器的行为**依赖几何**。任何"改进规划"的实验，如果控制/制导不变，都必须验证"改变几何是否改变了参考速度"。

### 1.8 D 路径：末端 4 m 的水平段

S4 的第五个候选：在最后 4 m 用一段**水平**（沿 x 轴）的直线收尾，而不是让路径以任意角度接近终点。

动机：终端捕获阶段需要一个"可停住的几何"——如果路径最后一段是斜的，船在刹车时容易越过终点平面；水平段给了明确的"接近轴"。

它的证据是 **5 条真实 pilot**（F0/F1/F2 × P0/P2/P4），不是 18 真实矩阵。文档里反复强调这个边界，因为"5 条"和"18 条"在统计上完全不是一回事。

## 2. 严谨版：学术总结

### 2.1 A* 的形式化

设占用栅格 `G = (V, E)`，`V ⊂ Z²` 为自由节点，`E` 为 4/8 邻接且满足"连续段碰撞检查"的边。

```
g(v)  = 从起点到 v 的最小已知代价
h(v)  = max(0, ‖v − g*‖ − tol)        （到目标区域的距离下界）
f(v)  = g(v) + h(v)
cost(u,v) = ‖p_u − p_v‖₂
```

**可采纳性**：`h(v) ≤ h*(v)` 对所有 `v` 成立（因为容差区域内的真实剩余代价为 0，区域外为欧氏距离减容差）。
**一致性**：`|h(u) − h(v)| ≤ cost(u, v)`（三角不等式），故无需重开已关闭节点。

**最优性**：在给定 `(V, E)` 与连接器集合上，A* 返回 `g` 最小的路径。
**非最优性来源**：`(V,E)` 是连续空间的离散化，最优格点路径 ≠ 最优连续路径；分辨率越小越接近，但节点数按 `1/Δ²` 增长（`max_grid_nodes = 250000` 即此约束）。

**剪枝的正确性**：`g + h > max_path_length ⇒ 真实代价 > max_path_length`，因为 `h` 可采纳。故剪枝不丢可行解。

**资源上限的三类失败**：

| 状态 | 含义 |
|---|---|
| `INVALID_START` / `INVALID_GOAL` | 端点本身违反净空/边界 |
| `NO_PATH` | 该分辨率下有限图不连通 |
| `LIMIT_REACHED` | 扩展节点或网格规模超预算 |

三者的区分很重要：`NO_PATH` 是**图**的性质，`LIMIT_REACHED` 是**预算**的性质，不能互相替代。

### 2.2 节点认证 vs 边认证

```
is_pose_valid(v, ρ)      → 节点级（等价于零长段检查）
is_segment_valid(u,v,ρ)  → 边级（连续扫掠检查）
```

栅格构造只做前者；搜索扩展时对**每条候选边**做后者。因此：

- 路径有效性 = `∀v: 节点有效 ∧ ∀(u,v) ∈ P: 边有效`
- 该结论**与分辨率无关**（不会因为格子大而漏检），但**连通性依赖分辨率**（格子太大可能找不到本存在的通道）。

这是"安全与完备性分离"：安全性由连续检查保证，完备性由分辨率与预算决定。

### 2.3 贪心捷径的性质

```
j* = max{ j > i : is_segment_valid(p_i, p_j, ρ) }
```

**保序性**：`j* > i`，路径参数单调。
**不保全局最优**：跨过 `p_{i+1}` 可能跳过更优的局部绕行。
**安全性**：每条新边都经 `is_segment_valid` 验证，故结果仍满足净空约束。
**拓扑改变**：捷径可能改变路径的同伦类（例如从"绕过障碍上方"变成"从缝隙穿过"），因此"捷径后路径"与"原路径"在拓扑上不一定等价——这是 S4 中 B 与 A 差异巨大的根本原因之一。

### 2.4 候选打分的性质

```
cost(P) = L(P) + w_t Σ|Δχ| + w_c ∫ max(0, c_pref − c(s)) ds + w_s Σ max(0, s_pref − L_i) + w_u N_turn
```

权重 `(w_t, w_c, w_s, w_u) = (1, 2, 2, 0.25)`，`c_pref = 0.75 m`，`s_pref = 4.0 m`。

**性质**：

- 单位混用（米、弧度、米²），故 `cost` 无物理量纲，只能用于**同一场景内的相对排序**；
- 采样近似积分（`sample_spacing = 0.1 m`），非解析积分；
- 只在**有限候选集**（≤ 5 条）内取最小，非连续优化。

**归因声明**：代码里显式写入 `evidence_status='UNKNOWN'`，表示"实际进入、记忆与走廊未匹配"——即不声称该代价能预测闭环表现。

### 2.5 等速参数化的性质

```
s_k = Σ_{i<k} L_i,   t_k = s_k / v_nom,   ψ_k = atan2(Δz_k, Δx_k),   ν_k = (v_nom, 0, 0)
端点：ν_N = 0,  ψ_N = ψ_{N−1}
```

**性质**：

- 时间最优性：**否**（等速，非 bang-bang）；
- 动力学可行性：**否**（`ψ` 可在拐点跳变，`q` 未限幅）；
- 可复现性：**是**（纯几何 + 常数速度）。

`sample_reference` 的插值语义：位置线性、姿态取**出向段**（outgoing）姿态、端点保持零速。这使参考在拐点处**姿态跳变**，是显式设计而非缺陷——G12 用速率限制吸收它，A 栈的 PID 用 `q` 反馈吸收它。

### 2.6 圆角 fillet 的误差界

设转角 `α`，半径 `R`，trim `t = R tan(|α|/2)`，采样数 `n`。

```
弓高  σ = R(1 − cos(|α|/(2n)))
弦长  c = 2R sin(|α|/(2n))
```

采样步长上界由两约束取小：

```
Δθ ≤ min( 2 arccos(1 − σ_max/R),  2 arcsin(c_max/(2R)) )
```

**安全性论证**：圆弧 ⊂ 弓形 ⊂ 弦的 `σ`-胶囊体。故

```
is_segment_valid(p_k, p_{k+1}, ρ + σ)  ∀k  ⇒  ∀q ∈ arc: dist(q, ∂O) ≥ ρ
```

**保守性**：半径额外加 `σ` 是必要代价——否则只验证了弦，没验证弓形。

**不可平滑的显式拒绝**（返回 `UNSMOOTHABLE` 而非部分结果）：

```
REVERSAL_REQUIRES_DIFFERENT_PATH     |α| ≥ π
ADJACENT_TANGENT_REGIONS_OVERLAP     t_i + t_{i+1} > L_i
LOOKAHEAD_TOO_LONG_FOR_ARC           Δ > 0.8 · arc_length
STRAIGHT_CONNECTOR_UNSAFE
ARC_SWEPT_CAPSULE_UNSAFE
OUTPUT_PATH_INVALID
```

**可见性约束**（`Δ ≤ 0.8·arc_length`）是一个容易被忽略的**制导-规划耦合条件**：几何平滑只有在制导能"看见"时才有效。

### 2.7 S4 消融结果与归因

**几何**

| 方案 | L (m) | Σ\|Δχ\| (°) | max\|Δχ\| (°) | min clearance (m) | 拐点 |
|---|---:|---:|---:|---:|---:|
| A | 18.485 | 765.0 | 45.0 | 1.803 | 17 |
| B | 17.207 | 69.8 | 40.3 | 1.526 | 2 |
| C | 17.073 | 69.8 | 1.4 | 1.526 | 2（+62 段离散小转角） |

共享一次 A* 搜索：展开 179 节点，约 0.159 s。

**闭环（同一 G12 / F0 / P0）**

| 方案 | t_arr (s) | 净距 (m) | RMS (m) | max err (m) | max pitch (°) | 饱和 |
|---|---:|---:|---:|---:|---:|---:|
| A | 132.90 | 1.630 | 0.1950 | 0.5332 | 53.10 | 0% |
| B | **52.45** | 1.565 | **0.0837** | **0.2218** | 66.82 | 0% |
| C | 59.10 | 1.199 | 0.1716 | 0.4545 | 61.03 | 0% |

**B vs A**：`Δt = −60.5%`，`ΔRMS = −57.1%`，几何长度仅 `−6.9%`。
**C vs B**：长度 `−0.78%`，`max|Δχ|` 从 40.3° 降到 1.4°，但 `Δt = +6.65 s`、`RMS ×2.05`、净距 `−0.37 m`。

**归因结论**（与文档一致）：

1. B 的收益主要来自**大幅减少转向次数**（17 → 2），而非缩短长度；
2. C 的退化与 G12 的 **bend-based 速度规划**一致：几何改变 → `bend` 改变 → 参考速度改变 → 时序改变；
3. 该机制解释**可信但未被独立消融隔离**，故不能声称"平滑有害"这一普遍命题。

**证据边界**：单场景、单水流（F0）、单初始态（P0）、三条 Python；不含真实后端；`_01/_02/_03` 为预登记中断，均保留。

### 2.8 局限

1. **无动力学可行性**：A* 与等速轨迹均不考虑转向半径、加速度、`q` 限幅。
2. **静态环境**：`WorldModel` 不支持动态障碍；`OccupancyGrid` 假设构造与搜索期间环境不变。
3. **二维**：仅 `x-z` 平面，无三维绕行、无横向机动。
4. **捷径改变拓扑**：可能从"绕行"变为"穿越缝隙"，使消融对照不再同伦。
5. **候选权重无物理量纲**：只能同场景排序。
6. **圆角半径固定**：`R = 1 m` 不随速度/通道宽度自适应；相邻短段易触发重叠拒绝。
7. **规划容差可为 0**：S4 中 `goal_tolerance = 0`，此时"目标区域"退化为点，A* 依赖精确终点连接器。
