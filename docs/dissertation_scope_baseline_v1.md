# Dissertation 研究范围与完成标准 v1

日期：2026-10-25。状态：用户已确认的项目范围基线；不代替院系评分细则或导师最终意见。

工作题目：**基于 LOTUSim 的欠驱动 UUV 点到点导航仿真系统开发与验证**。

English: Development and Validation of a LOTUSim-Based Simulator for Underactuated UUV Point-to-Point Navigation.

## 1. 研究定位

交付一个支持非线性欠驱动动力学、静态障碍、恒流、基础规划和闭环跟踪的仿真系统。路径规划为必要组成部分；提出新规划算法不是最低毕业交付的前提。明确区分平台已有能力、自研实现、配置与验证工作。

主链路：场景定义 → 规划 → 路径引导 → 控制与执行器分配 → 动力学积分 → 实时状态反馈 → 实际轨迹安全与到达验收。

## 2. 固定研究问题

**RQ1：如何建立并验证一个具有非线性和欠驱动特性的 UUV 仿真模型？**

说明方程、参数、假设、坐标系、执行器与欠驱动关系；验证输入响应、数值积分和状态转换。

**RQ2：如何将环境、基础规划和控制集成，使 UUV 在静态障碍环境中完成点到点导航？**

证明规划地图与仿真环境一致，实时状态驱动控制，运动由动力学而非位姿回放产生，实际轨迹满足安全和到达条件。

**RQ3：水流和执行器限制如何影响导航性能与可执行性？**

用无流/恒流对照评价误差、安全距离、到达时间、饱和及失败边界。

## 3. 固定范围

| 项目 | 最低范围 |
|---|---|
| 任务 | 单 UUV 点到点导航，纵向 x-z 平面 |
| 模型 | 非线性、欠驱动；3-DOF 或经验证的 6-DOF 纵向实验 |
| 地图 | 已知静态障碍、边界、起点、目标 |
| 环境扰动 | 无流和均匀恒流 |
| 规划/控制 | 一种基础规划方法、基础速度/姿态控制与路径引导 |
| 状态 | 仿真真值；不声称包含感知/估计 |
| 展示 | Gazebo 与离线轨迹、误差和控制曲线 |
| 真实性 | 可解释的合成模型；无辨识依据不得称为真实艇型模型 |

排除：三维规划、动态障碍、声呐/SLAM、复杂流场、波浪、实艇验证、新最优规划算法、MPC/强化学习、TerminalApproach 扩展、长期定点保持。已有工作保留，但不自动成为新模型验证证据。

## 4. 六项最低完成标准

| 编号 | 标准 | 必须交付的证据 |
|---|---|---|
| C1 | 模型方程、参数、坐标与欠驱动关系一致 | 模型说明、执行器映射、响应与数值验证 |
| C2 | 可配置障碍、起终点和恒流 | 三个复现场景、地图与仿真一致性检查 |
| C3 | 实际动力学闭环 | 指令、实际输入、状态和仿真时间记录；导航中无 MOVE 回放 |
| C4 | 名义工况安全到达 | 实际轨迹、到达判定、安全距离和跟踪误差 |
| C5 | 对照与适用边界评价 | 无流/恒流、饱和、失败案例与原因分析 |
| C6 | 可复现系统和完整论文 | 固定依赖、配置、命令、记录、图表和 dissertation |

六项全部完成才称最低交付完成。失败结果不得隐藏。困难工况允许失败，名义验收失败则需修复，不能直接改称困难工况。

## 5. 最低实验集合与论文贡献

实验顺序：动力学基本验证 → 无障碍跟踪 → 三个静态障碍任务 → 相同任务无流/两种非零恒流对照 → 水流或转弯难度递增的边界测试。

贡献：明确模型和执行器接口；建立环境到动力学反馈的闭环；通过实验评价导航性能与限制。系统集成应包含技术实现和验证，不能只展示安装平台或播放轨迹。

潜在会议论文可进一步研究路径平滑、提前转向或速度规划，但不阻塞本范围的完成，也不预先承诺发表。

## 6. 时间安排与变更管理

- 第1周：最终模型、执行器分配、坐标/时间一致性、基础闭环。
- 第2周：场景、LOS/基础规划、无流安全导航。
- 第3周：恒流对照、敏感性和初稿。
- 第4周：补关键实验、复现及论文修改。写作从第1周开始。

允许在开发/校准阶段调 PID，但必须记录。正式评价前冻结模型、场景、控制参数、阈值、代码及依赖哈希。若后续改变研究范围、模型或验收阈值，建立新版本，解释原因并重新运行所有受影响工况；不覆盖 v1 或旧结果。
