## 模型差异及证据

响应残差基本不随步长减小而下降，说明其主要来源不是积分误差。

锁定 `naval-group/lxdyn@363668b2b1f97e3177d2d617586fee6c4a727262` 的源码中：

- [Sim.cpp:185](https://github.com/naval-group/lxdyn/blob/363668b2b1f97e3177d2d617586fee6c4a727262/xdyn/core/Sim.cpp#L185) 使用 `solid_body_inertia` 计算 Coriolis/向心力。
- [Body.cpp:342](https://github.com/naval-group/lxdyn/blob/363668b2b1f97e3177d2d617586fee6c4a727262/xdyn/core/Body.cpp#L342) 使用包含附加质量的总惯性逆矩阵求加速度。
- 当前 twin axial 外力配置包括推进器、阻尼和恢复力，没有另外加入附加质量 Coriolis 力；原 `physics/uuv_3dof.py` 包含该项。

仅在诊断参考中抵消该项后，dt=.05 的 Python/xdyn 最大位置差降至 8.87×10⁻¹¹ m，俯仰差 3.02×10⁻¹⁰°，速度差 5.35×10⁻¹³ m/s。这为上述原因提供了直接数值证据。正式 M6 始终比较原 Python 方程，没有使用这个诊断来提高通过率。

能量检查通过不能排除遗漏此类不做功的耦合项。因此保留“有限容差通过”和“方程尚未对齐”两个结论。
