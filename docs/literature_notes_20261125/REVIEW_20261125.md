## 4. 方法与假设层面的三个系统性问题

复核中反复出现的不是单点错误，而是三种模式：

1. **把"通用做法"写成"该文做法"**。L06-2 最典型：题名里的 "variable-structure" 被我读成了增益切换，实际指双环。同类风险还有 L06-2 的"条件积分"、L12-3 的"clothoid 还是样条"——这些都已标 `△`，但读者容易忽略。
2. **把弱条件写强**。L04-1 的 "sufficiently smooth" 被我补成"二阶可微"；L05-2 的"位置与速率约束"在笔记里简写成"箱式约束"，丢掉了速率约束这一半。
3. **降维标签粗糙**。凡是"平面运动"就写 3H，但 L04-1 是一般类、L06-2 是分通道、L13 系列是水平面——三种"平面"不等价。矩阵的自由度列已按此修正了两处，其余待核。
4. **把后人的等价表述写成原文**。A* 的 `h ≤ h*` 不是 Hart 1968 的原话（原文是"算法可采纳"）；栅格的 log-odds 更新不是 Elfes 1989 的写法（原文是概率形式）。这类"正确的错误"最难发现——结论没错，归属错了。
