## 3. 用这张表找空白：四种"整列/整行失衡"

### 3.1 整列空白：**"时变/实测海流的闭环"这一列是空的**

- 矩阵里"海流模型"取值为 `时变` 的行：**0 行**。
- `实测` 只有 L21 两行，而它们是**数据源**，不是闭环控制器。
- 也就是说：**"实测流时序 → 闭环 → 规划层退化"这三件事同时出现在一篇里的情况，在这 49 条中一次都没有出现。**（注意分寸：这是"本清单内"的观察，不是"全世界没人做过"的断言；写进论文时应表述为"在本文所调研的范围内"。）

> 这不是"没人想到"，而是"三件事凑不齐"：有实测流的（NOAA）不做控制；做控制的（LOS 三篇）只假设常值；做分配的（Johansen）不管流。**凑齐需要一个人同时愿意做数据、仿真、控制三件事——这正是本项目的定位。**

### 3.2 整列空白：**"欠驱动 + 饱和 + 平滑"三列没有一行同时非空**

逐行检查：凡"欠驱动 = 是"的行，其"执行器饱和"列要么是 `无`，要么是 `部分`（L04-2）或 `抗饱和`（L06-2）；后两行都不涉及路径平滑。反过来，凡"路径平滑"非空的行（L11、L12），"欠驱动"列全是 `否` 或 `—`。

含义：**平滑算法假设载具能精确跟随任意曲率；而欠驱动载具恰恰不能。** 这条缝在两边的文献里都没被缝上。

### 3.3 整列空白：**"规划"与"饱和"从未同时出现**

"规划算法"非空的行里，"执行器饱和"列全部是 `—` 或 `无`。规划器不知道推力上界，分配器不知道路径几何。这就是 L15（规划—控制耦合）说的那个缺口的**表格化证据**。

### 3.4 整行失衡：**验证平台几乎全在"仿真"**

- `海试`：0 行（L03-1 可能含水池/湖试，标 △）。
- `池`：2 行（L03-1、L06-2，均待核对）。
- 其余 40+ 行是 `仿真` / `理论` / `综述` / `方法`。

含义：**整个"UUV 规划—控制—流"文献的方法论大厦，几乎全部建立在仿真与理论上。** 这不是本项目的缺陷，而是领域现状——但它意味着"仿真验证"在这领域是被接受的标准，同时"仿真里成功"不能当作强结论。

## 5. 三句可以直接用的 gap 陈述

写综述时，gap 陈述要"有出处、有余地"，下面三句是按矩阵空白写的，句中括号填具体文献：

> **G1（流）**：现有抗流引导方法（[L13]）与流估计方法（[L07]）均以海流恒定、无旋、空间均匀为前提，而公开实测数据（[L21]）表明真实流速具有显著时变性与垂向结构；将实测时序注入闭环后，引导—跟踪链的退化程度尚未见系统评估。

> **G2（执行器）**：控制分配与抗饱和文献（[L05]、[L06]）在过驱动平台上已相当成熟，但欠驱动 UUV 的可达集本身受限，且规划器（[L08]、[L09]）在生成路径时不考虑推力上界，导致"路径可达"与"指令可达"之间存在未被检验的缺口。

> **G3（验证）**：现有 AUV 规划—控制研究绝大多数在仿真中验证（矩阵"验证平台"列），且普遍以真值状态作为反馈；在缺乏实艇数据的条件下，仿真结果的可信度应被限定在"方法在该模型假设下有效"（[L19]、[L22]）。
