## 1. 这份台账要解决什么

笔记回答"这篇论文做了什么"，台账回答**"这句话凭什么写"**。每一条都是以"**断言 → 原文 → 直译 → 引用边界 → 取证动作**"组织的，目标只有一个：写论文时不必翻原文，也不会把话说大。

## 2. 证据等级（先读这一节，否则会误用）

| 级别 | 含义 | 能不能直接引用 |
|---|---|---|
| **A** | 摘要中的完整句子，逐字取得，词序连续无歧义 | 可以，注明"摘要" |
| **B** | 摘要中的片段（短语/半句），词序连续，但两端被截断 | 可以，用省略号，**不得补词** |
| **C** | 仅给定位与检索锚点，原文待从 PDF 摘录 | **不可以**，必须先补录 |

**A/B 级的来源说明**：本工作区里没有这 49 篇的原文 PDF（唯一相关的 `Literature_review_UUV.pdf` 是你 2026-02 的旧综述草稿，引用体系为 [1]–[8]，与本清单不重叠）。A/B 级文字来自 OpenAlex 的公开摘要索引（逐词带位置），我按位置重建、并只保留词序可验证的连续片段。**重建不是抄写**，因此凡有任何一个虚词无法从索引唯一确定的片段，我一律降级到 C，不放进来。

**一句话总结这份台账的性质**：它不是"我读完 35 篇后的摘录"，而是"**在只能拿到摘要的条件下，把每条断言的证据状态摊开**"。真正能直接引用的只有 24 条，其余 23 条是待办。

## 5. 怎么补录 C 级（10 分钟一条）

1. 打开 PDF，用检索锚点里的关键词搜（多数是作者原词，命中率很高）。
2. 把**完整句**抄进台账的"原文"栏，句尾标 `p.XX`（或 `§X.Y`）。
3. 把级别从 C 改为 **D（正文逐字）**——这是最高级，写进论文时优先用它，因为摘要往往把限定条件省掉了。
4. 若原文与"拟写入论文"的表述不一致，**改论断，不改原文**。台账的价值就在这里。

> 一次性把 PDF 放进 `docs/refs/`（文件名用 BibTeX key，如 `lekkas2014integral.pdf`），我可以批量补录并把 D 级引文回填到笔记里。

## 6. 三条铁律

1. **摘要不等于正文。** 摘要常省略前提（"straight-line"、"constant"、"in the absence of obstacles"）。台账的"引用边界"一栏专门记这些省略。
2. **限定词不能删。** 如 Lekkas 的积分 LOS 原文限定 *straight-line path following*，就不能写成"曲线路径下消除常值流误差"。
3. **C 级不进正文。** 未经原文核对的引文，宁可用"（见 L13-2）"这样的间接表述，也不要编一句英文。
