## 摘要（初稿，待正文定稿后修订）

本文开发并验证一个基于 LOTUSim 的欠驱动 UUV 点到点导航仿真系统，研究范围限定于已知静态障碍环境中的纵向平面任务。系统以可解释的合成非线性模型为动力学基础，采用两台轴向推进器产生纵向力与俯仰力矩，通过场景配置、路径构造、G12 引导、PID 控制与执行器分配连接 xdyn 动力学求解器，并记录 ROS/IPC 状态反馈及 Gazebo 位姿回写。模型响应、数值积分、坐标和时间一致性通过分项试验核验。冻结配置下，正式 Python 参考矩阵 54/54 通过，正式 GUI 真实动力学矩阵 54 条均实际执行，其中 53 条通过逐条原验收；九组均通过既定组验收和重复性标准。一个反馈停滞与清理故障导致的历史失败原样保留。有限边界评价显示三档增强向上恒流在 Python 中未通过，真实运行被门禁拒绝；两档阻尼扰动在 Python 与真实后端通过。独立 S4 研究比较原始 A*、安全捷径、圆角及水平终点接近路径，说明几何平滑与闭环表现不能等同；终点候选完成 18/18 Python 验收及五条有界 GUI 小试。另以单站实测流时间序列开展描述性对照。结论适用于本研究的合成模型、真值反馈、已知静态场景和已测流输入，不代表实艇或任意海况性能。

## 1 研究问题、范围与贡献

研究问题分为三项：RQ1，如何建立并核验具有非线性与欠驱动特性的 UUV 仿真模型；RQ2，如何把环境、规划、引导、控制、分配和求解器连接为实际状态反馈闭环；RQ3，水流与执行器约束如何改变安全、跟踪和到达表现。最低范围为单艇 x–z 纵向点到点导航、已知静态障碍、无流与均匀恒流。系统采用仿真真值，不包含感知、定位估计、动态障碍或实艇参数辨识。S4 与单站实测流是后续扩展性演示，不重定义最低范围或正式验收分母。范围与完成标准以 E00 为准。[需文献：研究背景与相关工作]

本文贡献定位为可审计的系统集成与验证：明确动力学和执行器接口，建立路径到实际动力学反馈的控制链路，并通过名义矩阵、边界评价和复现试验界定其适用范围。使用的 A*、路径捷径、圆角、LOS 类引导与 PID 不能被描述为本文新发明的算法。

## 3 模型与任务定义

### 3.1 合成模型与欠驱动性

xdyn 中的 `uuv_twin_axial_v2` 为合成六自由度模型，本文验证与任务设计集中于纵向运动。模型文件给出刚体惯量、附加质量、线性和二次阻尼、恢复项及附加质量耦合；Python 纵向参考用于独立数值比对。它验证的是实现与设定方程的一致性，而非对某艘实艇的预测精度。最终正文须把模型配置中的矩阵和单位逐项展开，并与实际求解器输入核对。[需文献：所用海洋航行器动力学形式；需图表：模型参数表]

两台理想可逆轴向推进器的推力分别为 `Tu`、`Tl`，每台限幅 ±15 N，安装偏置为 ±0.25 m。执行器映射为 `X=Tu+Tl`、`Z=0`、`M=0.25(Tl−Tu)`。输入矩阵秩为 2，不存在直接升沉控制；可实现的联合包络为 `|X|+4|M|≤30`。分配器对超出包络的请求按同一比例缩放，再把实际分配结果反馈给控制器的抗饱和机制。被动水动力产生的升沉力不能误写成直接升沉执行器。证据为 E01/E07/E08 及 `ros2/twin_axial_v2/allocation.py`。[需图表：执行器与坐标示意]

### 3.2 坐标、环境与验收

规划使用 x–z 平面。仿真世界、求解器与艇体分别使用 ENU、NED/FRD 等坐标约定，路径、状态反馈和 Gazebo 位姿须通过明确定义的变换连接。M7 对现有记录的逆变换与时间步长进行了核对。论文最终版须从 `protocol.py` 和实际记录逐项填写变换式，避免把规划深度直接当作 Gazebo 高度。名义实验包含 S1–S3 三个静态障碍场景、P0–P4 五个初态和 F0/F1/F2 三种恒流；重复条目为各组 P0_repeat。规划整段净距下限 1.5 m，真实轨迹安全下限 0.9 m；二者用途不同。逐条验收另要求 300 s 内到达、目标半径 0.5 m 保持 2 s、路径 RMS ≤0.35 m、最大误差 ≤0.8 m、实际俯仰 ≤75°及原速度、角速度与饱和限制。最终引导参考俯仰限幅 70°，与实际姿态验收阈值不得混写。E00/E04/E05。[需图表：原场景、初态和阈值表]

### 3.3 模型验证

M1–M7 分别覆盖执行器与欠驱动映射、静止、零态响应、能量衰减、步长收敛、Python/xdyn 配对以及坐标与时间。无流撤力后的能量测试、减半步长收敛和恒流配对均有记录；这些说明在已测试输入与数值设置下参考实现和求解器相符。M3 报告的加速度是 0.05 s 有限步估计，不能称为求解器瞬时导数输出；M6 也不是实艇验证。逐项数值、输入及限制见 E01–E03/E08。[需图表：M1–M7表、能量与收敛图]

## 4 规划、引导与实际闭环

冻结系统的主链路为场景配置、参考路径、G12 引导、PID、双推进器分配、xdyn 数值积分和状态反馈。Gazebo 接收实际求解器状态的位姿回写，用于场景展示和一致性核对；艇体运动不能用预先录制路径回放替代。运行记录同时保存目标、请求力/力矩、分配推力、实际状态、导航量、位姿和结束协议。真实后端在启动前核对冻结源码、配置、Python 证据、联合传输探针和运行资源；新鲜度与 guard 失效时不启动正式导航。原始失败、门禁拒绝和故意 abort 分开保存。E05/E07/E11。[需图表：数据流与结束时序]

正式 S1–S3 使用冻结 G12 路径与引导，不应笼统标为“未经处理的 A* 路径”。为了展示规划处理的作用，独立 S4 研究在五障碍宽通道中比较：A 原始栅格 A*、B 同一搜索结果加安全捷径、C 在 B 上加安全圆角、D 在安全捷径后加约 4 m 水平终点接近段。四者共享冻结动力学、G12、PID、分配器、场景与验收阈值，但参考路径不同。A/B/C 的 F0/P0 Python 消融、D 的三流五初态 Python 验证和五条 GUI 真实小试分属不同证据层级。[需文献：A*、路径后处理和引导方法；S4图表已生成]

## 5 实验设计与统计口径

正式名义评价共有 3 场景 × 3 恒流 ×（5 名义初态＋1 次 P0 重复）＝54 条。Python 参考先行，再启动真实 LOTUSim/xdyn GUI。逐条通过以完整原验收为准；组验收 N6 要求五初态至少 4/5、P0 成功且无安全违规。重复性 R2 还要求 P0 和重复自身均通过、时间覆盖和位置/到达/终止差符合原标准。因此“九组通过”与“54条全部通过”不是同一个结论。失败条目的截断 RMS 只描述已记录前缀，不可当作完成任务的全程指标。E04/E05。

边界实验单列 S2/P0 三档增强向上恒流以及 F0 下两档阻尼系数扰动。强流先经过 Python 门禁，未通过者不运行真实后端。独立环境 Python 复现、后续五条 GUI 复现、S4 规划研究和实测流研究各自另列分母，不与正式54条合计成功率。实测流 v10 取 NOAA CO-OPS pm0101 单站六采样窗口，在 60–150 s 显式渐入，二维控制修正仅使用东西向分量；北向保留元数据，不构成二维 x–z 修正。该试验是时间变化输入的有限示例，不是三维空间海流场试验。[需图表：实验队列与数据来源表]

## 6 结果

### 6.1 正式名义矩阵

冻结 G12 Python 参考矩阵 54/54 通过，九组重复性通过。正式 GUI 真实动力学矩阵 54 条全部实际运行，53 条逐条通过；45 个名义条目中 44 条通过，九次重复自身均通过，九组均满足 N6/R2。S3 的 18 条真实记录全部通过。唯一正式失败为 S1/F1/P4：约 13.5 s 后状态反馈停滞，随后清理失败，任务未到达。其已记录前缀安全不能使该条通过；后续独立 GUI 复现成功也不能替换原失败。反馈停滞的初始原因尚未证实。E04/E05。[需图表：九组结果、完整轨迹及失败标记]

S3/F2/P2 是代表性窄裕量工况，正式真实记录最小净距约 0.91617 m，相对 0.9 m 安全阈值仅约 16.17 mm。该试验通过原验收，但窄裕量应与成功结论同时报告，不能外推任意流速或模型扰动。E05。[需图表：净距、误差、俯仰和双推力全过程]

### 6.2 有限边界与复现

增强向上恒流的三档 Python 试验未满足原验收，真实门禁据此拒绝启动；其中拒绝记录不能写成真实动力学碰撞。两档阻尼扰动以独立配置测试，Python 和 GUI 均通过；较大阻尼档的真实 RMS 余量较窄。该组采样点显示限制位置，不给出连续参数的精确临界值。E06。

在同一台机器的独立 Windows Python 环境中，离线测试 1217 项通过，重新运行的 Python 54/54 与历史状态文件逐字节一致；后续针对性的五条 GUI 复现均通过原验收。它们增强了复核信心，但不等于在新机器或空 Nix 缓存环境完成全链路迁移。E10/E11。[需图表：历史与复现差异表]

### 6.3 S4 规划演示

S4/F0/P0 中，A/B/C 三条 Python 闭环均通过。A 到达 132.90 s、RMS 0.1950 m；B 为 52.45 s、0.0837 m。C 的最大离散转角显著小于 B，但到达为 59.10 s、RMS 为 0.1716 m，说明该地图中更平滑的几何路径没有自动改善冻结控制器的跟踪。旧 B 扩展到三流后，F0/F1 各 6/6 通过，F2 六条均失败，问题集中于终点接近与保持段。独立 D 候选保留安全捷径并加入水平终点段，Python 18/18 与三组严格重复性通过；所选 S4/F0/P0、F1/P0、F2/P0、F2/P2、F2/P4 五条 GUI 小试均通过原验收。最紧的真实最大误差为 F2/P2 的 0.73143 m，距 0.8 m 阈值约 68.57 mm。D 尚无完整18条 S4真实矩阵；旧 B 的六条 F2 失败不被删除。几何与闭环图、CSV及输入哈希见 `deliverables/s4_planning_demonstration_20261118/`。

### 6.4 时间变化水流的有限演示

独立水流对照使用 S3/F2/P0、P2 的恒流、合成分段流 v4 与单站实测流 v10 记录。v10 的 P0/P2 及各自重复均通过原验收；P0/P2 到达时间为 137.00/137.50 s，最小净距为 1.12753/1.13129 m，RMS 为 0.29679/0.29573 m。恒流 F2 对应净距约 0.91868/0.91617 m，而合成分段 v4 约 0.91648/0.91395 m。三者施加的水流方向与时序不同，数值变化仅作描述性比较，不能据此排名控制算法或推断复杂海况鲁棒性。较早的分段流失败记录仍属边界证据。来源及图表见 `artifacts/current_comparison_20261119_01/`。[需核对 NOAA 数据稳定引用及采样元数据]

## 7 讨论、限制与结论要点

RQ1 的证据支持合成欠驱动模型和指定纵向工况中的实现一致性，不支持实艇参数准确性。RQ2 的正式记录支持已知静态场景中的实际动力学闭环与按原组标准的名义完成，同时存在一条未到达的工程故障。S4 显示路径后处理的效果须由闭环指标判断，不能只看长度或曲率。RQ3 的结果说明性能受流输入与约束影响：窄裕量名义成功、强流门禁拒绝、阻尼端点通过、时间变化流有限对照应并列解释。Python 参考、真实 xdyn 与纯可视化回放不能混为一种证据。

主要有效性限制包括：合成参数、理想推进器、真值反馈、纵向和静态场景、离散边界采样、单站短时实测流、S4真实小样本，以及同机复现范围。下一步交付工作为完整外部文献核验、剩余正式图表、可迁移运行入口和独立目录恢复检查、学院格式及导师审阅；这些是论文和发布收尾，不应在结论中表述为已经完成。
