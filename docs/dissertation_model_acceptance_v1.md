# 最终模型设计与数值验收基线 v1

日期：2026-10-25。关联：[研究问题与范围](dissertation_scope_baseline_v1.md)。

**状态：确定后续实现的设计基线和验收目标，尚未实现或通过新模型验收。本文数值是项目工程标准，不是实验结果、商业设备规格或院系评分标准。** 本轮只写文档，不改变现有算法、配置或冻结数据。

## 1. 最终设计决定

新模型 ID：`uuv_twin_axial_v1`（待创建）。合成中性浮力 UUV，两个上下分置的可逆轴向推进器；研究 x-z 平面点到点导航。

Python 3-DOF 作为参考方程；首选实际后端为 LOTUSim/xdyn 六自由度积分、纵向平面工况。不能将其写成强制约束的 3-DOF，也不能每步归零出平面状态。原 `uuv_minimal_xdyn_v1` 与冻结实验完全保留。

前2–3个工作日核查锁定 xdyn 的耦合项和恒流支持。若不能实现并通过下述一致性验收，记录技术决定，将现有 Python 3-DOF 封装为 LOTUSim 外部动力学服务；研究问题和输入配置不变，但必须更新实现版本及论文表述，不冒称 xdyn 验证，不用回放替代积分。

## 2. 坐标、模型与水流

- 规划坐标 `(x_p,z_p)`：x 向前/东，z 向上。Gazebo ENU 为 `(x_p,0,z_p-20 m)`。起点默认 `(2,-10)`，对应深度30 m。
- FRD 艇体：x 前、y 右、z 下；q、theta 为抬头正。初始朝 ENU +X，转换到 NED 时须处理航向旋转，不能直接抄同一个 yaw。
- 纵向状态 `(x,z,theta,u,w,q)`；w 向艇体下方为正，保持为动态变量。
- 中性浮力、完全浸没、均匀恒流；无风浪、无接触碰撞响应。水流影响相对速度和水动力，而非直接平移轨迹。
- 参考模型保留刚体/附加质量耦合、二次阻尼、姿态运动学及正弦恢复项。恒流在惯性系固定，艇体系流速随姿态变化。禁止把艇体系分量也当常量。

| 参数 | 纵向参考值 |
|---|---|
| 刚体矩阵 | diag(20 kg,20 kg,8 kg·m²) |
| 附加质量矩阵 | diag(5 kg,8 kg,2 kg·m²) |
| 线性阻尼系数 | diag(4,6,3)，平移为 N/(m/s)，转动为 Nm/(rad/s) |
| 二次阻尼系数 | diag(1,1.5,0.5)，分别按速度/角速度平方计 |
| 俯仰恢复项 | 动力学右端 `-6 sin(theta)` Nm |
| 密度/重力 | 1000 kg/m³，9.81 m/s² |
| 积分 | RK4，0.05 s；验证用0.025 s及0.0125 s |

若使用六自由度扩展：刚体 diag(20,20,20,8,8,8)，附加质量 diag(5,5,8,2,2,2)，线性阻尼 diag(4,6,6,3,3,3)，二次阻尼 diag(1,1.5,1.5,0.5,0.5,0.5)，滚转恢复 `-6 sin(phi)`，偏航无人工恢复。须核对与参考纵向方程的一致性。

上述为合成有效参数，不能从外观自动推导，更不是辨识值。6 Nm 恢复系数可作为20 kg中性浮力载具约0.0306 m浮心/重心间距的等效解释；本版本仍只计一次等效恢复项。不得又加入完整静水恢复而重复计力。

## 3. 执行器：两个独立输入，缺少直接升沉力

上推进器位置 FRD `(0,0,-0.25)` m，下推进器 `(0,0,+0.25)` m；均沿 +X，输入 Tu、Tl，单位N，分别限制 [-15,15]。不包含电机滞后、RPM、死区或噪声。

`X=Tu+Tl; Z=0; M=0.25(Tl-Tu)`。

输入矩阵（行 X,Z,M）为 `[[1,1],[0,0],[-0.25,0.25]]`，秩2。欠驱动来自缺少直接升沉通道，而不是控制器主动不用某个已有执行器。

分配：`Tu=(X-4M)/2; Tl=(X+4M)/2`。联合可行域 `|X|+4|M|<=30`（力N、力矩Nm）。纯前进极限30 N、纯力偶极限7.5 Nm，不能同时取得。

v1 采用方向保持的统一缩放：先求未限幅 Tu/Tl，再令 `alpha=min(1,15/max(|Tu|,|Tl|))`，零输入时 alpha=1；两路都乘 alpha。记录请求、分配、实际施加及 alpha，抗饱和使用实际广义力，不能只使用旧独立限幅。

## 4. 任务尺寸与运行包络

- 新展示几何及所有附件必须位于长1.2 m、宽0.3 m、高0.7 m的中心包围盒内。
- 平面碰撞验收采用半径0.70 m圆盘：大于该纵向包围盒半对角线约0.695 m。安全裕度0.20 m，即艇中心距障碍表面/边界至少0.90 m。全程检查扫掠段，不能只查采样点。
- 名义前进速度0.40 m/s，可在弯道/目标附近降低；目标前进速度限幅0–0.60 m/s。执行器仍允许反推制动。
- 目标俯仰限幅±60°，实际 |theta|>75°判运行包络失败；实际 |u|或|w|>1.5 m/s、|q|>0.8 rad/s判失败。
- 六自由度模式监测相对初始规划平面的偏移：|y|<=0.05 m，|roll|<=2°，航向偏差<=2°；超限判平面假设失效，不偷偷投影/归零。
- 控制与记录20 Hz仿真时间；沿用0.25 s仿真时间/1 s墙钟命令过期归零。仿真暂停时不得继续积分；性能指标不使用墙钟。

## 6. 固定最小场景和试验矩阵

以下为**待新建**场景，不修改原场景或冻结数据。所有坐标为规划平面米，边界均 `[0,20]×[-20,0]`，起点 `(2,-10)`、目标 `(18,-10)`、初始水平静止。

| ID | 障碍矩形范围 (x,z) | 用途 |
|---|---|---|
| S1 single_baffle_v1 | `[9,10]×[-20,-8]` | 简单绕障 |
| S2 double_baffle_scaled_v1 | `[6,7]×[-20,-7]`，`[13,14]×[-13,0]` | double-baffle结构的新模型场景；不冒称原冻结场景原样复现 |
| S3 double_baffle_tight_v1 | `[6,7]×[-20,-5.5]`，`[13,14]×[-14.5,0]` | 较紧的上下转向空间 |

障碍三维展示沿y挤出覆盖平面任务；安全由上述几何评估。正式评价前只做几何连通性和艇体包络预检；动力学可行性正是待检验内容，不能预先宣称保证成功。

水流为规划世界坐标 `(v_x,v_z)`：F0=(0,0)，F1=(-0.05,0) m/s，F2=(0,+0.05) m/s。水流在相同场景内是唯一环境自变量；三种流不分别调PID。

每组合5个固定初态：P0无扰动；P1 z+0.10 m、pitch+3°；P2 z-0.10 m、pitch-3°；P3 x+0.10 m、pitch-3°；P4 x-0.10 m、pitch+3°。全部初态仍须通过包络安全预检。

共3场景×3水流×5初态=45次正式导航。采用同一控制器与规划配置；随机规划器固定种子0并记录，初态改变时允许重新规划。不得以不同失败重试替换某个规定工况。确定性重复单独增加，不充当鲁棒性样本。

压力测试：S2/P0额外测试向上恒流0.10、0.15、0.20 m/s。失败允许但必须归类报告，不纳入N6名义成功率。水动力敏感性：S2/P0/F0将全部阻尼系数一起乘0.8和1.2，各运行一次，同一控制器；报告差异，不能宣称由此覆盖所有参数不确定性。
