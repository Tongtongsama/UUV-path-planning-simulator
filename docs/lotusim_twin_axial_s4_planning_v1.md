## 审计与贡献边界

| 模块 | 已有能力 | 本轮处理 |
|---|---|---|
| planner/algorithms/grid/astar.py | 欧氏启发式、4/8 邻接、起终点连接、整段碰撞验证、搜索上限和节点计数 | 原样复用，0.5 m、8 邻接 |
| trajectory/generator.py | 去重、最远可见点贪心捷径、保留拐点的折线重采样、逐阶段验证 | 原样复用；其定速时间戳不输入 G12 |
| planner/candidates.py:simplify_path | 去重和同方向共线点消除，保留 U 转 | 原样复用；不是曲线平滑 |
| feasible_v2 / feasible_matrix guidance.build_path | 一、双挡板专用几何构造、二次 Bézier 圆角、整段净距检查 | 不能直接生成任意多障碍路径；冻结版本不改 |
| g12_matrix/runner.py | 已验证的 G12 引导、RK4 动力学、PID、分配、原 Python 验收 | 直接调用原 run_case，只临时注入 S4 路径、场景 XML 和“不适用”的旧稳态证书说明 |

新增能力仅为独立通用圆角适配和受控三组比较，不宣称发明 A*、捷径或 Bézier 算法。最终参考是已检查的折线，不宣称解析曲线连续曲率或动力学可行性证明。旧 G12 正式记录不是 A* 路径结果，不能重标为此次规划升级结果。

## 预登记场景和对照

边界 x∈[0,20]、z∈[-20,0]，起点 (2,-10)、终点 (18,-10)。五个岛状矩形（xmin,xmax,zmin,zmax）：

1. (8,10,-11,-9)，遮挡直达路径，存在上绕/下绕选择；
2. (4,6,-18,-14)；
3. (13,15,-6,-2)；
4. (13,15,-18,-14)；
5. (3,5,-6,-2)。

布局增加环境障碍和路由选择，但不要求每个障碍都迫使轨迹转向。此场景不等同于多次连续避障或困难迷宫。规划净距 1.5 m；原实际安全阈值 0.9 m 不变。场景在观察比较结果前固定，不按成败修改。

| 对照 | 路径处理 |
|---|---|
| A | 原始 A* 折线 |
| B | 同一 A* 结果 + 原有安全捷径 + 共线点消除 |
| C | B + 安全二次圆角 |

三者统一以不超过 0.05 m 间距细分并保留拐点，使用同一冻结 G12、F0、P0。C 的 trim 上限 1.5 m 且不超过相邻边长的 40%，按 1、1/2、1/4、1/8 倍固定尝试，每段均验证；全部失败则保留原拐点。保存每个被拒绝的平滑尝试，不根据动态结果调参。

先保存全部几何结果，再各运行一次闭环。几何无效则记录拒绝；闭环失败保留完整前缀，不重跑替换。保留原 300 s、到达半径/保持、RMS、最大误差、净距、姿态、速度、角速度及饱和标准。

几何指标：长度、非零转角数、总转角、最大离散转角、整段最小净距、A* 展开节点、搜索和后处理墙钟时间。圆角的离散转角数随采样增加，不能直接解释为更多机动；同时看总转角与最大转角。共享一次 A* 搜索使路径比较确定；单次时间不用于统计性能结论。

扩展条件：C 通过全部原 Python 检查，且相对 A/B 有跟踪或到达收益，再考虑有限扩展；不自动启动三流、多初态或真实仿真。本轮不能证明鲁棒性或普遍优越性。
