用途：与陆博士及其他评审沟通“做了什么、证据是什么、还差什么”。这是评审材料，**不是**完整论文或已验证可迁移的软件发行包。所有比率按原实验队列分别报告，不把后来复现替换原失败。

## 推荐的一句话介绍

我们在限定的纵向导航任务中，完成了非线性欠驱动 UUV 模型、静态障碍与水流配置、规划—引导—PID—双推进器分配—xdyn 反馈的真实闭环，并用冻结配置完成名义矩阵、边界评价和代表性复现；进一步通过 S4 展示规划后处理与终点接近段的作用，并以单站实测海流时间序列完成有界真实对照。
